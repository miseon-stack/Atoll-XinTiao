# Work Tempo 2.3.3-beta.1 公开试用版

面向 Apple Silicon（M 系列）Mac 的中文刘海工作台，包含实时收益、快捷启动面板、日程待办及截图录屏等现有功能。保留 Work Tempo 名称和确认的产品图标。

普通用户下载 `WorkTempo-2.3.3-beta.1-arm64.dmg`，打开后将 Work Tempo 拖入“应用程序”，弹出镜像，再从应用程序文件夹启动。无需 Xcode 或编译源码。
