# Work Tempo 朋友试用版：安装与检查

这是公开提供的未公证 Beta 试用包，不是已完成苹果公证的正式版。维护者选择先开放下载，其他 Mac 的首次安装与完整功能实测仍待完成，请勿将本机自动检查理解为跨机兼容保证。软件无需安装 Xcode 或其他开发工具。

## 适用设备

- Apple Silicon（M 系列）Mac；第一轮建议使用带刘海的 MacBook。
- 应用声明要求 macOS 14.6 或更新版本；最低版本及不同机型仍需要实际验证。
- 此包不支持 Intel Mac，不适用于 Windows。
- 仅临时（ad-hoc）签名，没有 Developer ID 签名和苹果公证。macOS 可能拦截首次启动；能否正常打开必须实测。

## 安装

1. 从官网 https://work-tempo.adonisghenry.chatgpt.site 或项目的 GitHub Releases 下载 DMG；首次试用请同时保留本说明和 SHA256SUMS.txt。不要下载陌生人修改的副本。
2. 双击 DMG，把 Work Tempo 拖入窗口中的 Applications（应用程序）文件夹。
3. 如果已有 Work Tempo 或旧 Atoll，先停止安装并联系维护者，不直接覆盖，也不要同时运行两个版本。
4. 弹出磁盘镜像，从“应用程序”打开 Work Tempo。
5. 若系统提示开发者无法验证，先确认来源和文件完整性。确认可信后，可查看“系统设置 → 隐私与安全性”是否提供该应用的“仍要打开”。受管理的电脑可能不允许此操作。
6. 如果显示“将损坏电脑”、恶意软件或文件损坏，请停止使用并反馈完整提示；不要关闭 Gatekeeper、SIP 或运行陌生终端命令绕过保护。

苹果官方说明：https://support.apple.com/zh-cn/102445

## 第一次使用

- 展开屏幕顶部的刘海区域，查看收益和常用工具。
- 配置工作时间与薪资后查看实时收益。测试可以使用虚构数字，不必向维护者提供真实薪资。
- 展开刘海，点击顶部键盘形状的 Launcher 按钮打开快捷启动面板；也可按 Control + Option + Q。
- 若快捷键有冲突，先使用鼠标按钮或菜单栏入口，在设置中调整快捷键。
- 截图/录屏、日历/提醒事项、文件访问等功能可能分别申请权限；仅为你需要使用的功能授权。权限未授予时请记录提示，不要把全部权限盲目打开。
- 软件会在当前 Mac 创建自己的本地配置，不包含开发者的薪资、日程、快捷启动项目或文件授权。可选联网功能可能仍需网络或你自己的账号/API 配置。

## 请帮忙检查这 8 项

请在没有安装旧版、没有开发环境的另一台 Mac 上测试；把每项记录为“通过 / 失败 / 未测试”。

- [ ] 能获得完整 DMG，并正常打开镜像、拖入应用程序。
- [ ] 弹出镜像后，应用仍能从应用程序文件夹打开；记录第一次打开的所有系统提示。
- [ ] 刘海入口可以展开，设置示例薪资后能看到实时收益。
- [ ] 鼠标 Launcher 按钮和 Control + Option + Q 都能打开面板。
- [ ] 分别添加一个应用、网站、测试文件和测试文件夹，并能打开；拖放添加可用。
- [ ] 完全退出并重新打开后，收益设置和快捷启动项目保留；文件需要重新授权时提示明确。
- [ ] 用虚构测试配置完成一次导出、修改和导入恢复；不要用真实个人配置测试破坏性操作。
- [ ] 按需授权后，日程待办、截图/录屏可用；停止录屏后仍能打开刘海和快捷启动面板。

请反馈：Mac 芯片、macOS 版本、每项结果，以及失败时的提示/截图。截图前遮挡姓名、日程、薪资、文件路径等个人信息。不要发送 API 密钥或导出的个人配置。

## 更新与卸载

此轮使用手动下载更新，不承诺自动更新可用。保留配置后再更新；已有开发版与本试用版的设置身份不同，不直接覆盖开发者本人当前安装。

卸载时先退出软件，再把 Work Tempo.app 移到废纸篓。配置不会随应用自动删除，方便重新安装恢复；需要清理配置时请先导出备份再向维护者确认具体路径。
